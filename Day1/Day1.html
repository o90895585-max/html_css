# 핵심 구성 정리 html을 시자하겠다는 태그 , 문서선언 ! 느낌표 누른 뒤 엔터 누르면 위 기본 구성이 다나옴. html을 시자하겠다는 태그 , 문서선언 최상위 태그 설명 데이터 탭이름으로 표시 되게 함 <meta charset="UTF-8"> 한글 깨짐 방지 <meta name="viewport" content="width=device-width, initial-scale=1.0"> 뷰포트 설정 <body> 수집 데이터, 실제로 웹에서 보이는 정보 - body 한칸을 한줄로 인식함 - 만약 줄바꿈을 하려면 <br>을 써야함 <h1> 웹 속 재목 1~6까지 있음 <h6>의 경우는 각주 개념으로 씀 <hr> 문단을 선으로 나눌때 <p> 내용 (문단으로 분류됨) 항목,리스트 만들기 <ul> 항목 나열 할 때 점으로 나옴 <li> 내용을 쳐줘야 리스트가 나옴 <ol> 숫자로 항목 나열 type=“A" 를 하면 항목이 영어로 # 태그 속성 지정 type=“I”로 하면 로마 숫자 <li> 내용을 쳐줘야 리스트가 나옴 테이블 = 표작성 <table> 표 작성 =border=“1” 할시 표 행,열 선 생김 # th = 테이블 헤더 tr = 테이블 row(행) <th> 표 헤더 <tr> 표 내용 (헤더 안에 들어갈 내용> <th> 표 헤드 셀 하나 이미지 <img src=“" alt=""> src = 여기에 사진링크 넣으면 웹에 나옴, 또는 저장된 사진 이름 alt = 자료를 잘 못 가져왔을 때 하이퍼링크 <a href="">구글</a>로 이동 - a 내부에 하이퍼링크 들어갈 글자 넣고 - 따옴표 안에 링크를 넣어줘야 함 입력칸 <form action=""> action 따옴표 안에는 서버주소를 적을 것 <input type="search" name="q" placeholder="이름 입력"> - ## type 안에는 여러 유형이 가능함 - password = 비밀번호 칠 때처럼 어떤 문자든 점으로 나옴 - email = 뒤에 이메일 주소가 안올시 오류 알림이 뜸 - search = 검색창 - ## name=“q”를 쓸 시 = 액션에 지정한 서버로 바로 보내줌 - ## placeholder="이름 입력" = 따옴표 안에 검색창 예시 문구가 들어감 - <button>”내용”</button> 내용이라고 쓴 곳에 버튼 안에 들어갈 문구를 넣으면 됨 </form>
